# Testing Skill

## Purpose

Ensure new and existing functionality is reliable through comprehensive testing of business logic, APIs, validation, and
database interactions.

---

## Responsibilities

Test:

- API endpoints.
- Service layer.
- Validation logic.
- Database operations.
- Business rules.
- Error handling.

---

## Test Types

- Unit tests
- Integration tests
- API tests

---

## Best Practices

Tests should be:

- Independent
- Repeatable
- Readable
- Fast
- Deterministic

Use the Arrange–Act–Assert pattern.

---

## Coverage

Verify:

- Successful execution.
- Validation failures.
- Business logic.
- Error scenarios.
- Edge cases.
- Regression prevention.

---

## Quality Checklist

- High coverage
- Clear assertions
- Minimal duplication
- Easy maintenance
