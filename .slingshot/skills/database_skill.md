# Database Skill

## Purpose

Design and maintain scalable MongoDB data models, validation rules, and database interactions for NutriChef AI.

---

## Technology Stack

- MongoDB Atlas
- Beanie ODM
- Pydantic

---

## Responsibilities

- Design collections.
- Create Beanie models.
- Define indexes.
- Create request and response schemas.
- Validate incoming data.
- Optimize database operations.

---

## Best Practices

- Use meaningful field names.
- Separate database models from API schemas.
- Define indexes for commonly queried fields.
- Avoid duplicated data where possible.
- Use asynchronous database operations.

---

## Validation

Ensure:

- Required fields.
- Optional fields.
- Default values.
- Type validation.
- Business rule validation.

---

## Performance

Optimize:

- Query efficiency.
- Index usage.
- Database reads.
- Database writes.

---

## Quality Checklist

- Validated
- Indexed
- Scalable
- Maintainable
- Consistent
