# Frontend Development Skill

## Purpose

Develop responsive, reusable, and maintainable frontend features for NutriChef AI using React and Material UI while
following the project's architecture and coding standards.

---

## Technology Stack

- React 19
- Vite
- React Router
- Material UI (MUI)
- Axios

---

## Responsibilities

When implementing frontend functionality:

- Build reusable components.
- Develop responsive pages.
- Integrate backend APIs.
- Handle loading, success, and error states.
- Follow the existing project structure.

---

## Best Practices

- Keep components focused on a single responsibility.
- Reuse components whenever possible.
- Centralize API calls.
- Avoid duplicated logic.
- Keep UI and business logic separate.
- Use meaningful component names.

---

## State Management

Prefer:

- useState
- useEffect
- Context API

Avoid unnecessary global state.

---

## API Integration

- Use the centralized API layer.
- Handle request failures gracefully.
- Validate responses before rendering.
- Display loading indicators during asynchronous operations.

---

## UI Guidelines

Ensure:

- Responsive layouts.
- Accessible components.
- Consistent spacing.
- Consistent typography.
- Theme compliance.

---

## Quality Checklist

- Responsive
- Reusable
- Accessible
- Easy to maintain
- Consistent with project design
