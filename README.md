# NutriChefAI

NutriChef AI is an AI-powered smart kitchen assistant that generates personalized recipes based on available ingredients, dietary preferences, health goals, and budget.
Using Slingshot and the AI-SDLC approach, the application will be built end-to-end with AI assistance across requirements, design, development, testing, and deployment.
Key features include:
1. Smart recipe generation from available ingredients
2. Pantry tracking and expiry-based suggestions
3. Ingredient substitution recommendations
4. Leftover food rescue ideas
5. Nutrition insights and healthy alternatives
6. Step-by-step cooking assistance
