# API Schemas

This document summarizes the request and response schemas exposed by the NutriChef AI backend.

---

# Pantry

## IngredientRequest

```json
{
  "name": "Tomato",
  "quantity": 2,
  "unit": "pcs",
  "category": "Vegetables",
  "expiry_date": "2026-08-01",
  "notes": "Fresh"
}
```

---

## IngredientResponse

```json
{
  "name": "Tomato",
  "quantity": 2,
  "unit": "pcs",
  "category": "Vegetables",
  "expiry_date": "2026-08-01",
  "notes": "Fresh"
}
```

---

## PantryResponse

```json
{
  "ingredients": [
    {
      "name": "Tomato",
      "quantity": 2,
      "unit": "pcs",
      "category": "Vegetables",
      "expiry_date": "2026-08-01",
      "notes": "Fresh"
    }
  ]
}
```

## Notes

- Request schemas are used for API input validation.
- Response schemas define the structure returned by the backend.
- Validation errors follow FastAPI's standard `HTTPValidationError` format.
- Detailed field definitions can be viewed in the OpenAPI documentation (`/docs`) generated by the backend.
